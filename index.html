B.Tech Final Year / Semester Mini-Project

MailCraft AI – Smart Email Generator

An intelligent, context-aware Natural Language Processing (NLP) web platform engineered to bridge the professional communication divide for engineering students, faculty, and corporate professionals.

Problem Statement & Objectives

Undergraduate students and entry-level engineering graduates frequently encounter hesitation, etiquette ambiguity, and language barriers when writing high-stakes emails—such as requesting assignment extensions, applying for competitive internships, or communicating with department heads.

  • Automated Context Formulation: Synthesizes pertinent subject lines and body copy based on specific situational parameters.
  • Multi-Tone Adaptation: Adjusts formality from formal academic etiquette to urgent project escalations.
  • Trilingual Support: Provides fluent translation and Romanized Hinglish generation for Indian college environments.
  • Zero-Dependency Fallback: Operates fully client-side or with lightweight Python backend integration without mandatory cloud dependencies.

System Architecture & Tech Stack

Frontend: Semantic HTML5, Tailwind CSS, Vanilla ES6+ Modules
Styling: Navy Blue (#0F172A) & Purple (#7C3AED) Design System
Persistence: HTML5 Web Storage API (localStorage) + SQLite sync
Backend: Python 3 http.server REST API + Gemini/OpenAI Proxy

The architecture follows a dual-mode pattern: an intelligent local NLP heuristic generator works seamlessly offline, while an optional cloud LLM bridge (Gemini 1.5 / GPT-4o) provides enterprise-grade zero-shot completion without exposing keys to client viewers.

Key Examination & Viva Defense Points

Q1: How does MailCraft AI prevent hardcoded, rigid templates?

Unlike legacy template engines that merely concatenate static strings, MailCraft AI's dynamic synthesis engine parses semantic components from user topics (action verbs, entities, urgency level, reasons). It uses dynamic grammatical openers, context-aware elaboration modules, situational bullet point synthesizers, and matching closings that vary dynamically on each generation seed.

Q2: How are API keys and user privacy secured?

MailCraft AI guarantees privacy by defaulting to on-device zero-network generation. When configured with cloud LLMs, API keys are held strictly in client browser memory or server environment variables, preventing exposure in public source repositories.

Q3: How does the application support responsiveness and accessibility?

Built with responsive CSS Flexbox and CSS Grid layout primitives, standard ARIA labeling, high-contrast dark theme mode, keyboard accessibility, and dynamic word/character counter feedback.

AI Engine & API Configuration

Stored strictly in your local browser storage. Never sent to any third-party server.

Tip for College Project Evaluation: The default "Smart Dynamic Engine" runs 100% locally with zero configuration required. If presenting viva with external APIs, you can optionally provide your Gemini or OpenAI API key.
